BlackoutTracker 0.6 — Windows x64

Розпакуйте всю папку та запустіть BlackoutTracker.exe.
Python, Qt та інші залежності вже включено. Не переносіть EXE окремо від _internal.
Під час першого запуску оберіть чергу. Типове значення — 6.1.
У цій версії підтримується Київська область (ДТЕК КРЕМ).

Натисніть на іконку в треї, щоб відкрити графік.
Закриття вікна згортає програму в трей. Для завершення: права кнопка на іконці → Вийти.
Панель закріплена внизу праворуч на основному екрані, над панеллю завдань.
Кнопка «Розгорнути» показує графік і подробиці; «Згорнути» повертає компактний вигляд.
Чергу можна змінити у вікні «Налаштування». Автозапуск Windows поки не вмикається.

Типово оновлення раз на 2 хвилини; у налаштуваннях можна обрати 1–30 хвилин. Після 30 хвилин без успішної перевірки джерела дані
позначаються застарілими.
Усі години — Europe/Kyiv. Стан за графіком не підтверджує фактичний стан електромережі.

Під час розробки випускається лише portable-версія. Встановлення й видалення не потрібні.
Запуск: dist\BlackoutTracker\BlackoutTracker.exe або EXE у розпакованому ZIP.
Налаштування й кеш зберігаються в папці data поруч із EXE.
Переносьте всю папку разом із portable.flag, data та _internal.
Перед оновленням закрийте застосунок через меню трею «Вийти».
Збірка зберігає локальну папку data, а ZIP створюється без персональних налаштувань.
Для portable потрібна папка з правом запису. Інсталятор відкладено до завершення розробки.
Оверлей: за 5 хвилин до запланованого відключення з’являється таймер у верхньому
правому куті та лунає короткий сигнал. Попередження спрацьовує один раз для події
протягом сеансу, також при запуску за менш ніж 5 хвилин до відключення.
Клік по оверлею приховує його до наступної події. Для застарілих даних, можливих
або екстрених відключень автоматичне попередження не запускається.
Постійний оверлей вимкнений за замовчуванням. Його можна ввімкнути у налаштуваннях;
він показує також відлік до відновлення. Щоб повернути прихований постійний оверлей,
вимкніть і знову ввімкніть параметр. Звук можна вимкнути або прослухати в налаштуваннях.
Частота оновлення API не змінює щосекундну роботу таймера.
Автозапуск Windows поки не реалізовано.

Розробка:
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python app.py
.venv\Scripts\python -m unittest discover -s tests
powershell -ExecutionPolicy Bypass -File build.ps1

PySide6 / Qt використовуються як динамічні бібліотеки за LGPLv3;
ліцензії сторонніх компонентів постачаються в папці licenses.

Версія 0.6: налаштування виїжджають ліворуч у тому самому вікні, без блокування
головної панелі. Відкриття/закриття панелі та розгортання графіка анімовано (260 мс).
Звуки: три короткі тони, дзвінок, сирена. Вибір зберігається; є попереднє прослуховування.
